A single dad joke for make.fun's "Dad Joke Showdown" bounty: one line, one sentence, 124 characters, built around a dentist visit that turns into a cavity search. The program writes the joke to `entry.txt` and reads it back to prove the file matches the joke exactly.

## Run it

```sh
node main.ts
```
